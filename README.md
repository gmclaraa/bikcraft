> O **Bikcraft** é um site focado na comercialização e personalização de bicicletas elétricas sustentáveis sob medida. Este projeto foi desenvolvido durante os cursos da **Origamid**, onde aprendi bastante sobre estruturação de código, design responsivo e boas práticas de desenvolvimento front-end.

---

## 🎨 Sobre o Projeto

O projeto conta com páginas completas apresentando a marca, o catálogo de produtos detalhado, opções de seguro e uma página de contato/orçamento.

* **Design Responsivo:** Adaptado perfeitamente para celulares, tablets e desktops.
* **Experiência do Usuário (UX):** Transições suaves, elementos interativos em JavaScript e formulários funcionais.

---

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram empregadas no desenvolvimento do projeto:

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização avançada, uso de variáveis, Flexbox, Grid e design responsivo (Mobile First).
* **JavaScript:** Interatividade da interface, manipulação do DOM e lógica para os orçamentos/produtos.
